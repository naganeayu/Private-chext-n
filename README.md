# ISBN / ISSN NDL 所蔵検索 v0.2.4

Chrome Manifest V3 拡張です。閲覧中のページからISBN/ISSNを抽出し、国立国会図書館サーチのSRU APIの `LIBRARY` ファセットから図書館名を表示します。

## v0.2.4 の変更点（権限最小化）

- 閲覧中のサイトを読み取る権限を `activeTab` に変更。全Webサイトを対象とする `http://*/*` / `https://*/*` の恒常的なホスト権限を削除しました。
- `tabs` 権限も削除。拡張アイコンをクリックしたタブに対してのみ、一時的にタイトル・URLを参照し、`scripting` でISBN・ISSNを抽出します。
- 通信のために必要な `https://ndlsearch.ndl.go.jp/*` のホスト権限は維持します。これは **NDL API接続先** に限定したものです。
- **重要：対象Webページを開いた状態で拡張アイコン「N」をクリックしてサイドパネルを開き、その後「このページをスキャン」をクリックしてください。** サイドパネル内のボタンだけでは `activeTab` 権限は付与されません。
- 別サイトへの移動や新しいタブへの切り替え後は、対象ページで拡張アイコンを再クリックしてからスキャンしてください。
- ISBN/ISSN抽出・SRU API・HTTP 429の最大3回再試行・24時間キャッシュなどはv0.2.3と同じです。

## v0.2.3 から継承した処理

- HTTP 429（アクセス制限）が返された場合、**5秒後、さらに429なら10秒後**に自動再試行。初回を含めて最大3回です。429以外のHTTPエラー・タイムアウトでは自動再試行しません。
- `Retry-After` ヘッダーがある場合、指定された待機時間を優先します（短いときは最低5/10秒）。30秒を超える待機指示がある場合は再試行せず停止します。
- 3回とも429の場合は、その番号および残りの番号の照合を止めます。無制限には再試行しません。
- v0.2.2のリクエストヘッダー切り替えを削除しました。`fetch` に追加のリクエストヘッダーは設定しません。
- 「直接開いたSRU XMLを貼り付けて所蔵館を表示」を削除しました。
- 以前の「15分間のローカル待機」設定は破棄します。これはNDL側の429を回避できることを意味しません。
- SRU XMLに含まれるエスケープされた `facets` / `recordData` の読み取り、応答診断用のXML表示は維持しています。
- 所蔵館情報を取得できた結果は24時間キャッシュし、繰り返し照会を減らします。
- APIからの応答待ち時間は最大90秒です。429の再試行を含むと、照合にはそれ以上かかる場合があります。

## インストール

1. ZIPを解凍します。
2. Chromeで `chrome://extensions` を開きます。
3. 「デベロッパーモード」を有効にして、解凍したフォルダを読み込むか、旧拡張のフォルダを上書きして更新します。
4. ISBN/ISSNが載ったHTTP(S)ページを開いた状態でChromeのツールバーにある「N」アイコンをクリックし、その後サイドパネルで「このページをスキャン」を押します。

## 補足

- HTTP 429はサーバーによるアクセス制限です。再試行しても成功が保証されるわけではありません。繰り返しエラーになる場合は照会を控えてください。
- SRUの `LIBRARY` は検索結果全体の所蔵館集計であり、全所蔵館を保証するものではありません。
- iframe、画像、PDF内の文字はスキャン対象外です。

## アイコン

- Chromeツールバー用の小さなアイコン（16px, 32px）は「N」の1文字にしました。
- 大きなアイコン（48px, 128px）は「NDL」の3文字です。
- manifest.json の icons / action.default_icon に指定済みです。アイコン画像はv0.2.3のNアイコン版から変更していません。
- Webサイトのブックマークアイコン（favicon）そのものは、このChrome拡張では変更されません。
